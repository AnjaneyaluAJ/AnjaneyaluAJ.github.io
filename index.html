Part 4 · Scaling laws

Chinchilla-Style Scaling Laws: Predicting the Compute-Optimal Model Before Training It

23 training runs from 10M to 200M parameters at 1e17, 3e17 and 1e18 FLOPs on 4× NVIDIA A10G. The 1e18 prediction was committed to GitHub before those runs started.

At 1e18 FLOPsPredictedMeasured
Optimal size*77M74.7M
Loss3.1293.134

*Non-embedding parameters. One seed per point, so the 1e18 optimum could sit anywhere from about 61M to 83M.

Series B

Applied AI — From Demo to Production

What changes between an agent demo and a system an enterprise can run: security boundaries, failure handling, and evals that gate releases.

Part 1 · Reference implementation

Production Insurance Claims Assistant

A multi-agent claims assistant for a fictional motor and home insurer, built the way a regulated enterprise would need it: every risky path has a control in code, and every control has a test.

  • 23 behavioural & adversarial eval cases
Code: claims-assistant-reference → Write-up coming soon

What it demonstrates

  • Authorization in code at the data layer, not in the prompt
  • Prompt-injection defence on uploaded documents
  • PII redaction before any LLM call
  • Human-in-the-loop escalation to an adjuster
  • Graceful degradation when a dependency fails
